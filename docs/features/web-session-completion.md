# Web 会话状态与完成提醒

Web 会话列表通过颜色和文字共同展示需要关注的状态：蓝色“运行中”、绿色勾选“已完成”、橙色“需要权限”或“等待你的回答”。运行标记保持稳定，不要求用户观察小点闪烁。普通空闲、已归档和机器离线的列表行沿用原有展示。

后台对话的一轮执行从运行或等待用户操作转为空闲后，加入未读结果集合。断线和出现待回答的阻塞问题不算完成。开始新一轮执行会清除上一轮的完成标记，避免运行中仍显示旧结果。

Web 全局右上角显示未读完成通知，包含会话标题，点击沿用会话列表的跳转逻辑。通知不自动消失，打开对应会话后随已读状态一起移除；也可以逐条关闭，关闭通知不会清除列表中的未读完成状态。相同会话只显示一张通知，新一轮完成可以再次提醒。多条通知在限定高度内滚动，不截断队列。

正在查看的会话、侧边子对话、正在归档及已归档的会话不弹完成通知。通知复用本机内存中的完成/未读状态，不申请系统通知权限，不跨浏览器标签页同步，也不在页面刷新后恢复。

## 验证

本地 Expo Web 已运行且 CLI 已构建时，可执行 `pnpm exec node packages/happy-app/scripts/session-completion.e2e.mjs`。默认连接 `http://127.0.0.1:8989`，可通过 `HAPPY_COMPLETION_WEB_ORIGIN` 指定其他本地地址。脚本启动临时本地服务及测试账号，通过真实 Socket.IO 更新验证运行、完成、授权等待、关闭、再次完成和会话跳转，结束后清理服务及临时数据；报告和关键截图保存在 `.e2e-artifacts/session-completion-<时间>/`。
