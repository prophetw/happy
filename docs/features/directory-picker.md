# 目录选择器

首页创建会话时，点击项目目录会打开目录浏览列表，支持 iOS、Android 和 Web。

Web 首页创建器和“开始新会话”页面的目录浏览使用同一个居中对话框，新建页从 Project 路径栏右侧的“选择目录”打开。确认后应用目录或项目身份并关闭选择器；取消保留原选择。

## Web 目录选择交互

- 宽屏左侧为最近项目，右侧为当前目录；宽度小于 720px 时用“最近使用的项目 / 浏览目录”标签切换。标题、搜索、路径导航和底部确认固定，列表独立滚动。
- 最近项目、搜索结果和文件夹点击后都只改变待选目标，底部“将使用”显示实际路径或项目名称。只有“使用此目录 / 使用此项目”提交；关闭、取消或 Escape 丢弃本次浏览。
- 路径使用可点击的面包屑和返回上级按钮；Web 不再单独展开同级目录，进入父级即可查看。同级目录仍参与搜索。
- “编辑路径”和“输入自定义路径”在对话框内编辑，支持 POSIX、Windows 盘符、UNC 及 `~` 路径。回车跳转并预览，再通过底部确认提交；无效相对路径会提示，不会静默改成用户主目录。手动路径在启动会话时沿用原流程校验，因此离线或无目录读取权限时仍可填写。
- 搜索框及目录列表支持方向键移动、Enter 进入目标，Ctrl/Cmd+Enter 确认待选目标；编辑路径期间禁用确认，避免提交旧路径。中文输入法确认不会触发目录选择。
- 空目录、无搜索结果、无法浏览、读取中及读取失败分别显示；读取失败可重试。最近项目和只提供项目身份的 Happy Agent 项目保留原有选择能力，不推测其目录。

以下为共享目录读取能力和移动端交互；Web 的提交与布局规则以上述说明为准。

- 目录浏览列表顶部可搜索项目名、目录名及完整路径，支持忽略大小写和名称模糊匹配。结果优先显示完整匹配、名称前缀匹配，再到包含匹配及模糊匹配；带路径分隔符的输入只做路径包含匹配，避免相同上级目录导致大量无关结果。
- 搜索范围为所选机器的最近项目（Expo iOS 为所有机器的最近项目），以及当前目录和上级目录中已经加载的文件夹，不递归搜索整台机器，也不随输入发送新的目录读取请求。结果显示名称和路径，点击即可选中；重复路径保留最近项目入口，只有项目身份的项目仍按身份选择。
- 未输入搜索词时，最近项目优先展示，同级目录默认折叠；折叠不影响搜索。
- “开始新会话”页面的项目输入框用于搜索最近项目，搜索词与会话草稿分离。点击结果才应用实际路径或项目身份并关闭选择器；“输入自定义路径”切换为独立的路径输入，点击勾选或按完成键才应用，取消或关闭会保留原选择。
- 默认浏览已选目录；未选择目录时从所选机器的用户主目录开始。
- 浏览模式显示当前目录的子目录，展开同级目录可查看上级目录中的其他目录。点击文件夹进入，点击“返回上级目录”向上浏览。
- 浏览不会修改会话草稿。点击“使用此目录”后应用目录并关闭选择器；直接关闭会保留原选择。
- 保留最近使用的项目和“输入自定义路径”入口，包括只能由 Happy Agent 按项目身份解析的项目。
- 读取中显示进度；读取失败可重试，并继续返回上级、选择最近项目或手动输入。根目录不显示上级入口。

目录列表复用 Happy CLI daemon 已有的机器级加密 `listDirectory` RPC，不依赖先创建会话，不需要新增服务端接口。只显示目录，支持 POSIX 路径、Windows 盘符路径和 UNC 共享路径；导航变更或切换机器会丢弃过期请求结果。

浏览要求所选电脑有在线的 Happy CLI daemon。只有 Happy Agent 或机器离线时，最近项目和手动输入仍可使用，但无法读取目录列表。

## Web 与 Expo iOS 跨机器项目搜索

Web 的“开始新会话”页在配置卡片上方提供“所有机器”项目搜索。输入项目名或路径后，结果同时显示项目、机器、完整目录和在线状态；点击或使用方向键、回车选择后，一次更新机器与项目，并清除原工作树选择。搜索文字与任务输入独立，原有机器选择、目录浏览和自定义路径入口继续可用。

搜索复用已有 Fuse.js 名称及路径匹配；同等匹配程度下，在线机器优先，再按最近使用排序。同名目录在不同机器上分别展示，Happy CLI 与 Happy Agent 已配对的机器合并展示。离线机器的项目仍可选择，实际启动继续检查目标 daemon 是否在线。Web 未输入时展示前六项，输入后搜索全部已记录项目，不递归扫描远程文件系统。

Expo iOS 在首页创建器的项目选择器和“开始新会话”的目录行提供“所有机器”搜索。弹层中显示项目名称、机器、在线状态及实际路径，输入不会改变任务草稿，点选后同时切换机器与目录并清除旧工作树。当前机器离线也能打开搜索、选择其他机器；目录浏览和自定义路径仍针对当前选中的机器。首页复用已有跟随键盘的弹层，新建页使用可避让键盘的选择面板；取消保留原选择。本次不修改独立的 Swift/UIKit 客户端或 Android 入口。

Web 与 Expo iOS 使用独立的 `recentProjects` 设置保存最近 100 个机器与项目组合，通过现有加密设置在同一账号间同步并在本地缓存。首次使用会补入当前已加载、未归档的普通项目，并将 Happy 创建的 CLI 工作树归到主仓库；已有会话活动及成功创建会话会更新最近使用时间。只有项目身份的 Happy Agent 项目按 `projectId` 保存，不猜测目录。

记录不随聊天归档、删除、停止或机器离线移除；刷新后即使原会话不在接口最近 150 条记录中，已保存的项目仍然可用。超过 100 项时淘汰最早使用的记录；已移除机器的历史不展示。历史开始记录前已丢失的会话、尚未加载的项目不会自动恢复；被删除的实际目录在启动时仍由原流程校验。Web 的原机器内最近项目列表也读取这份历史。

浏览器回归脚本：先启动本地 Expo Web，再在仓库根目录执行 `pnpm exec node packages/happy-app/scripts/recent-projects.e2e.mjs`。脚本默认访问 `http://127.0.0.1:8989`，可用 `HAPPY_RECENT_PROJECTS_WEB_ORIGIN` 覆盖；会创建并清理临时 PGlite relay、账号及 daemon 测试夹具，检查跨机器搜索、离线目标、键盘选择、会话创建，以及归档和超过 150 条会话后刷新仍保留历史。报告与关键截图保存到 `.e2e-artifacts/recent-projects-<run-id>/`。

设置 `HAPPY_RECENT_PROJECTS_MOBILE_PREVIEW=1` 会额外打开仅开发环境可用的 `/dev/project-search`，以手机尺寸验证 iOS 复用的项目选择内容。此浏览器预览不等于 iOS 真机验收；系统键盘、原生安全区和模态层展示仍需在 iPhone 或 iOS 模拟器上确认。
